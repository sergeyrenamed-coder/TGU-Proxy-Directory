# RNMD Music Directory · экспериментальная схема

Это тестовая реализация **отдельной музыкальной директории** внутри TGU Proxy Directory. Пока размещена в ветке `experiment/rnmd-music-directory`; главная ветка и работа прокси не затрагиваются.

## Принцип работы

Пользователь открывает страницу TGU Proxy Directory. Обычно видит только прокси. Если в существующее поле поиска ввести **`music`** (регистр не важен), интерфейс переключится на RNMD Music Directory. Очистка поля возвращает таблицу прокси. Музыкальная директория **не добавляет источники в прокси-каталог**, не влияет на его статистику и не участвует в автоподборе.

Файлы директории независимы от прокси:
- `docs/data/music/providers.json` — публичный список провайдеров, статусов подключения и ограничений.
- `docs/data/music/tracks.json` — **пустой** проверяемый индекс, пока нет проверенных записей.
- `data/music/*` — их исходные копии.
- `scripts/music_directory.py` — пробный агрегатор метаданных **в отдельный preview-файл**.

## Источники v0.1

| Провайдер | Статус | Что нужно |
| --- | --- | --- |
| Openverse | Candidate | Проверить HTTP-доступ, реальные аудио-URL, права, RU-интернет |
| Jamendo | Awaiting client_id | Зарегистрировать приложение и проверить API/условия |
| PromoDJ | Pending | Найти согласованный документированный способ интеграции |

Оба языка тестируются поисковыми запросами на русском и английском, **но это не гарантия русскоязычных композиций**. Скрипт сохраняет язык как `unknown`, а не угадывает по алфавиту.

## Запуск пробного сбора (не публикует записи на сайт)

```bash
python scripts/music_directory.py --query "русская музыка" --query "indie pop" --output music-preview.json
```

Для дополнительного Jamendo API можно передать `JAMENDO_CLIENT_ID` через окружение. Токены и секреты никогда не добавлять в репозиторий или клиентское приложение.

## Проверка

```bash
python -m unittest tests.test_music_directory -v
node --check docs/assets/app.js
```

GitHub Actions в pull request выполняет тесты и отдельный **неблокирующий** сетевой smoke test. Ему может прийти 403 из-за сетевых или серверных ограничений, поэтому это не равно подтверждению доступности на мобильной сети РФ.

## Права и безопасность

**Не публикуем mp3 и не включаем автопоток на основании одной ссылки.** Openverse предупреждает, что не проверяет правовой статус записей. Прототип хранит атрибуцию, ссылку на оригинал, предполагаемую лицензию, и `rights_reviewed=false`. Перед фактическим публичным стримингом требуется проверить лицензию, доступность записи и условия соответствующего API. Пользовательский TGU-прокси для этого не используется.

Рабочий музыкальный сервис RNMD Music будет получать только опубликованный, отдельно проверенный каталог; эксперимент не подключается к стабильному RNMD Music APK автоматически.
